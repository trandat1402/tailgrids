# Gioi thieu Tailgrids

Tailgrids la thu vien component UI xay dung tren Tailwind CSS.

Trang nay la vi du mau cho thay cach dung chung mot layout (`_layouts/default.html`) va cau hinh chung (`_config.yml`) cho nhieu trang, thay vi lap lai header/footer o tung file HTML.
